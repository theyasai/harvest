# NFC 収穫管理システム 手順書

## 全体の仕組み

```
[作業者カード]  https://theyasai.github.io/harvest/?w=山田太郎
      │ iPhoneでタッチ → index.html が作業者名を iPhone 内に保存
      ▼
[コンテナシール] https://theyasai.github.io/harvest/?c=0001
      │ iPhoneでタッチ → index.html が「時刻・作業者・コンテナ・端末」をまとめて
      │                  location.href で GAS へ移動（fetch を使わないので CORS の問題なし）
      ▼
[GAS] スプレッドシートの「記録」シートに1行追加 → 「記録しました」画面を表示
      ▲
      │ 30秒ごとに読み込み（JSONP 方式なので CORS の問題なし）
[dashboard.html] 作業者別・時間帯別のグラフと表
```

## ファイル一覧

| ファイル | 置き場所 | 役割 |
|---|---|---|
| `index.html` | GitHub Pages | iPhone で開く記録画面 |
| `dashboard.html` | GitHub Pages | 管理者用ダッシュボード |
| `Code.gs` | Google Apps Script | スプレッドシートへの書き込み・データ提供 |
| `write_nfc.py` | 書き込み用パソコン | ACR122U で NFC シール/カードに URL を書き込む |

## 手順1：GAS（Google Apps Script）を設定する

GAS の URL はすでにあるので、**中身を `Code.gs` に入れ替えて、同じ URL のまま更新**します。

1. 記録用の Google スプレッドシートを開く
2. メニューの **拡張機能 → Apps Script** を開く
   （今の GAS がここから作ったものなら、そのプロジェクトが開きます）
3. 左の `コード.gs`（または `Code.gs`）の中身を**全部消して**、`Code.gs` の内容を貼り付ける
4. 上の方の `const ACCESS_KEY = 'ここに合言葉';` の「ここに合言葉」を、英数字20文字くらいの合言葉に書き換える
   （⚠️ 合言葉は GitHub には書かないこと）
5. 💾（保存）を押す
6. 左の ⚙️ **プロジェクトの設定** → タイムゾーンが **(GMT+09:00) 東京** になっているか確認
7. 右上の **デプロイ → デプロイを管理** を開く
8. 今のデプロイを選んで ✏️（鉛筆）を押す
9. **バージョン：「新バージョン」** を選ぶ
10. 次の設定になっているか確認して **デプロイ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
11. 「アクセスを承認」が出たら、自分のアカウントを選んで許可する
    （「このアプリは Google で確認されていません」と出たら **詳細 → 〇〇（安全ではないページ）に移動** で進めます）

> ⚠️ 「新しいデプロイ」を作ると URL が変わってしまいます。必ず **「デプロイを管理」→ 鉛筆 → 新バージョン** で更新してください。
> URL が変わった場合は、`index.html` と `dashboard.html` の先頭付近にある `GAS_URL` を書き換えてください。

> 💡 スプレッドシートからではなく、単体で作った GAS の場合は、`Code.gs` 上部の
> `SPREADSHEET_ID = ''` に、スプレッドシートの URL の `/d/` と `/edit` の間の文字列を入れてください。

**動作確認**：ブラウザで GAS の URL を開いて `harvest GAS OK` と表示されれば成功です。
URL の最後に `?action=data` を付けて開くと、今日のデータ（最初は空）が表示されます。

スプレッドシートには最初の記録のときに **「記録」シート**が自動で作られます。

| 日時 | 作業者 | コンテナID | 端末 | 受信日時 | 記録ID |
|---|---|---|---|---|---|

## 手順3：NFC 書き込み用パソコンの準備（Windows の例）

### 用意するもの
- ACR122U（USB カードリーダー）
- NFC シール・カード：**NTAG213 / NTAG215 / NTAG216**
  （MIFARE Classic は iPhone で読めないので使えません。コンテナ用は NTAG213 で十分です）

### インストール
1. **Python** を https://www.python.org/downloads/ からインストール
   インストール画面で **「Add python.exe to PATH」に必ずチェック**
2. ACR122U を USB に挿す（通常は自動でドライバが入ります。認識しない場合は ACS 社サイトから「ACR122U PC/SC Driver」をインストール）
3. スタートメニューで「cmd」と入力して **コマンドプロンプト** を開き、次を入力して Enter
   ```
   pip install pyscard
   ```

### 実行
1. `write_nfc.py` を好きなフォルダ（例：デスクトップの `harvest` フォルダ）に置く
2. コマンドプロンプトでそのフォルダに移動して実行
   ```
   cd Desktop\harvest
   python write_nfc.py
   ```
3. メニューが出ます

```
==== NFC 書き込みツール ====
 1. コンテナシールを連続で書き込む
 2. 作業者カードを書き込む
 3. 端末番号設定カードを書き込む
 4. 書き込み内容を確認する
 0. 終了
```

**1. コンテナシール**：開始番号・終了番号を入れて Enter（そのまま Enter で 1〜1000）。
シールをリーダーに置く →「OK」→ 外す → 次のシールを置く…を繰り返すだけです。
- 書き込み後に読み直して確認しています
- 途中でやめても（Ctrl + C）、次回は続きの番号から始まります（`progress.txt`）
- 書いた記録は `write_log.csv` に残ります（Excel で開けます）
- 💡 書き込んだシールにはすぐ番号をペンで書くか、先に番号ラベルを貼ったシールを順番に並べておくと間違えません

**2. 作業者カード**：名前を入れてカードを置くだけ。続けて次の人の名前を入力できます。

**3. 端末番号設定カード**（任意）：各 iPhone で一度タッチすると端末番号が設定されます。
（画面のボタンでも設定できるので、なくても大丈夫です）

**4. 確認**：シールやカードに何が書かれているか表示します。

> ⚠️ シールを「ロック（書き込み禁止）」する機能は付けていません。ロックすると二度と書き換えられないためです。

## 手順4：iPhone（5台）の準備

各 iPhone で1回だけ行います。

1. **Safari** で設定用リンク `https://theyasai.github.io/harvest/?device=01&key=合言葉` を開く
   （01 の部分を iPhone ごとに 01〜05 に変える。`write_nfc.py` の「3. 端末番号設定カード」で作ったカードをタッチしてもOK）
2. 「端末番号を設定しました」と出て、下の欄が「合言葉：設定済み」になれば完了（iPhone 本体にも番号シールを貼っておくと便利）
3. 確認事項
   - Safari の **プライベートブラウズはオフ**（オンだと作業者名が保存されません）
   - 設定 → Safari → **タブを閉じる → 「1日後」** にしておくと、タブが溜まりません
   - NFC で開くブラウザは「デフォルトのブラウザ」です。端末番号の設定も同じブラウザで行ってください

### NFC の読み取り方
- **iPhone XS 以降**：画面を点けて（ロック解除して）、**iPhone の上部（カメラ付近）** をシールにかざす → 通知が出るので **タップ**
- iPhone 7 / 8 / X：コントロールセンターに「NFC タグリーダー」を追加して、それを押してからかざす
- カメラ使用中・Apple Pay 使用中は読めません

## 毎日の使い方

1. 作業者が **自分の作業者カード** をタッチ →「作業者をセットしました ○○」
2. 収穫したら **コンテナのシール** をタッチ →「記録しました No.0001 ○○さん 本日 N ケース目」
3. 次のコンテナは、そのまま 2 を繰り返すだけ
4. 交代するときは、次の人が自分のカードをタッチすれば切り替わります

- 作業者のセットは **12時間で自動的に切れます**（翌日の付け忘れ防止）
- 同じコンテナを **60秒以内に再タッチ** した場合は「記録済み」と表示され、二重には記録されません
- 作業者・端末番号が未設定のときは **記録せずに** 警告が出ます

### 管理者
- パソコンやタブレットで https://theyasai.github.io/harvest/dashboard.html を開く
  （初回だけ合言葉を聞かれます。`dashboard.html?key=合言葉` で開くと入力を省けます）
- 30秒ごとに自動更新。日付を選べば過去の日も見られます

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「作業者が未設定です」と毎回出る | プライベートブラウズがオンになっていないか確認。デフォルトのブラウザが Safari 以外ではないか確認 |
| 記録画面の上に「Google ユーザーによって作成…」と出る | GAS の仕様なので問題ありません |
| 「合言葉が違います」と出る | 設定用リンクを開き直す。ダッシュボードは「合言葉」ボタンから入れ直す |
| ダッシュボードが「データ取得エラー」 | GAS のデプロイ設定「アクセスできるユーザー：全員」を確認。`Code.gs` を貼り替えた後に「新バージョン」でデプロイしたか確認 |
| 記録時刻がずれる | GAS のタイムゾーン（東京）と iPhone の時刻設定（自動）を確認 |
| `pip` が見つからない | Python インストール時に「Add to PATH」にチェックしたか確認。`py -m pip install pyscard` でも可 |
| 「カードリーダーが見つかりません」 | ACR122U を挿し直す。ドライバをインストール |
| 「NTAG213/215/216 ではないようです」 | シールの種類を確認（MIFARE Classic などは不可） |
| コンテナ番号の先頭の 0 が消えた | スプレッドシートの C・D 列の表示形式を「書式なしテキスト」に |

## セキュリティについて
- GAS の公開範囲は「全員」ですが、**合言葉がないと記録も閲覧もできません**
- 合言葉は GitHub には載せず、iPhone とダッシュボードを開くブラウザの中だけに保存されます
- 外部からできるのは、合言葉付きでの「1行追加」と「その日の記録を見る」ことだけです。スプレッドシートの削除・書き換えや、ほかのファイルを見ることはできません
- 合言葉が漏れたら、`Code.gs` の `ACCESS_KEY` を変えて「新バージョン」でデプロイし、各 iPhone で新しい設定用リンクを開き直してください
- iPhone を紛失した場合も、念のため合言葉を変えてください

## 補足
- 記録が何万行にもなって動作が重くなったら、古い行を別シートに移してください。
