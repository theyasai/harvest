# わが家の3Dモデル

間取り図のスクリーンショットから、次の流れで作った3Dモデルです。

1. 図面画像を拡大し、1Fと2Fに分割する
2. 寸法線をもとに、壁・建具・部屋・家具を `coords.json`（座標表、単位mm）に書き起こす
3. `generate.py` で座標表から `scene.json`（シーンJSON、単位m）と `index.html`（3Dビューア）を生成する
4. `index.html` をブラウザで開いて3D表示を確認する
5. 図面に壁を重ねた画像と3D表示を見比べ、ずれを直す（`python3 generate.py --check 1F.png 2F.png 出力先`）

修正するときは `coords.json` を編集してから `python3 generate.py` を実行してください。

- 原点は外壁の北西（図面の左上）の角です。x が右（東）、y が下（南）です。
- 図面に描かれていない窓とドア（1Fの各室のドアなど）は推定で入れ、`"assumed": true` を付けています。
- 階高は 2,900mm、屋根は陸屋根です。中庭は2層吹き抜けで、屋根を開けています。

## 改訂版の図面と修正案

`coords.json` は改訂版の図面を書き起こし、建築上の問題を直した修正案です。直した内容は `fixes`（3D上の番号ピンと一覧）に、設計者に確認したいことは `notes` に書いています。主な修正は次のとおりです。

- 土間の外壁が欠けていたので、外壁と玄関引き戸を追加
- 階段を基準法に合う14段の折り返し階段にし、1Fと2Fで位置をそろえた
- 1Fと2Fの外壁・中庭・水回りの壁の位置をそろえた
- 玄関、洗面、トイレ、和室、納戸など、入口のない部屋や動線をつないだ

## 平屋案

`coords_hiraya.json` は、2階建ての修正案を敷地を広げて平屋にした案です。`python3 generate.py coords_hiraya.json` で `scene_hiraya.json` と `hiraya.html` を生成します。

- 中庭を家の真ん中に置き、廊下・和室・LDK・土間で囲むロの字型
- 外寸 15.47×12.74m、延床 約161m²（約49坪）、敷地 約20.5×21.7m（約135坪）、駐車場2台
- 部屋名に `"jo": true` を付けると、面積から計算した帖数を表示します
