# わが家の3Dモデル

間取り図のスクリーンショットから、次の流れで作った3Dモデルです。

1. 図面画像を拡大し、1Fと2Fに分割する
2. 寸法線をもとに、壁・建具・部屋・家具を `coords.json`（座標表、単位mm）に書き起こす
3. `generate.py` で座標表から `scene.json`（シーンJSON、単位m）と `index.html`（3Dビューア）を生成する
4. `index.html` をブラウザで開いて3D表示を確認する
5. 図面に壁を重ねた画像と3D表示を見比べ、ずれを直す（`python3 generate.py --check 1F.png 2F.png 出力先`）

修正するときは `coords.json` を編集してから `python3 generate.py` を実行してください。

- 原点は外壁の北西（図面の左上）の角です。x が右（東）、y が下（南）です。
- 図面に描かれていない窓とドア（1Fの各室のドアなど）は推定で入れ、`"assumed": true` を付けています。
- 階高は 2,900mm、屋根は陸屋根です。中庭は2層吹き抜けで、屋根を開けています。
